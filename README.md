# ZYVEN CITY

A modern cross-device 3D city game prototype. Built as the web/game shell for the larger ZYVEN project.

## Current prototype
- Three.js 3D city with procedural buildings, roads, trees and a drivable vehicle
- Touch controls for phones and tablets
- Responsive HUD, minimap, mission panel and action buttons
- Vite + Vercel deployment configuration

## Roadmap
- Unity Android production client
- Online realtime multiplayer
- Nearby/local multiplayer
- NPC citizens, traffic and missions
- Vehicles, interiors, shops and dynamic weather
- Accounts, progression, cosmetics and leaderboards
- Dedicated authoritative multiplayer services

## Development
`npm install && npm run dev`
